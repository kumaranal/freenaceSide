# Freelance site (Next.js)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

Edit company name, email, phone and all copy in `src/lib/site.ts`.
Set `NEXT_PUBLIC_SITE_URL` (see `.env.example`) to your real domain so canonical URLs, sitemap, robots and Open Graph images are correct.
